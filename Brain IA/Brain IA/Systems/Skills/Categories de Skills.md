# Categories de Skills

#skills #categories #passifs #combat

## 11 Categories

### 1. Attack (Attaque)
- Frappes, lames, pression, chasse
- **Exemples** : Instinctive Strike, Deep Slash, Pressure Point
- **Effets** : Bonus degats, multi-hits, penetration armure

### 2. Defense
- Peau, parade, bouclier, resolve
- **Exemples** : Stone Skin, Iron Resolve, Minor Parry
- **Effets** : Reduction degats fixes et %, chances de parade

### 3. Agilite
- Esquive, reflexes, vitesse
- **Exemples** : Wind Step, Light Reflexes, Eldanior Suppleness
- **Effets** : +3-8% vitesse, +10% saut, +4-20% vitesse d'attaque

### 4. Chance (Luck)
- Critique, omen, esquive miraculeuse
- **Exemples** : Lucky Strike (+3% crit), Treasure Hunter (+5% loot)
- **Effets** : Multiplicateur critique 2.0x (300% degats totaux)

### 5. Magique
- Mana, arcane, sort
- **Exemples** : Mana Font (1.5x regen), Mana Heart (10.5x regen)
- **Effets** : Bonus mana, regeneration, bouclier arcane

### 6. Regeneration
- Vie, vampirisme, souffle
- **Exemples** : Cellular Regeneration, Spiritual Siphon
- **Effets** : +5-8% HP/END/Mana par attaque

### 7. Resistance
- Fortification, bulwark, immortalite
- **Exemples** : Tenacity, Adaptive Shield, Pain Tolerance
- **Effets** : Reduction fixe (2-4 degats) + reduction %

### 8. Vie
- Constitution, coeur, sang
- **Exemples** : Robust Constitution, Vital Blood, Heart of Oak
- **Effets** : +5 Vitality bonus max

### 9. Endurance
- Poumons, frenzy, forteresse
- **Exemples** : Tireless Breath, Thick Skin, Solid Stance
- **Effets** : +30 Endurance max

### 10. Detection
- Vision, pistage, sens
- **Exemples** : Eagle Eye, Night Vision, Sixth Sense, Tracker
- **Effets** : Range bonus, detection de furtivite

### 11. Maitrise (Weapon Mastery)
- Epee, hache, dague, arc, lance, baton
- **Exemples** : Sword Mastery, Axe Mastery, Dagger Mastery
- **Effets** : Bonus specifiques par type d'arme
